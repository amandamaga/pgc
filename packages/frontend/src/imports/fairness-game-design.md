Create a Design System and mobile game interface for children (ages 8–12) used in a behavioral experiment about fairness and decision-making.

The interface should follow a Duolingo-like educational game style: playful, colorful, simple, and easy to understand.

The system must include both:

A reusable design system

Game screens built using those components

The UI must prioritize clarity, large tap areas, minimal text, and quick decision making.
