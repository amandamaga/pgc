# 📚 Documentação do Sistema

Sistema completo para experimentos de punição altruísta com crianças de 6-10 anos.

## 📖 Documentos Disponíveis

### [TELAS-JOGO-VISUAL.txt](./TELAS-JOGO-VISUAL.txt) ⭐ RECOMENDADO
**Visualização ASCII de todas as telas do jogo**

Conteúdo:
- 🎮 Mockups visuais de TODAS as 7 telas
- 📱 Layout exato de cada componente
- 🔄 Fluxo resumido e metacontingências
- ✨ Fácil de visualizar e entender

### [ARQUITETURA-TELAS.md](./ARQUITETURA-TELAS.md)
**Visão completa da arquitetura de telas**

Conteúdo:
- 📂 Estrutura de arquivos completa
- 🗺️ Mapa de navegação (Dashboard + Game)
- 🔄 Estados e transições
- 📊 Dados mock (pares, rodadas)
- 🎯 Design system (cores, fontes, bordas)
- 🚀 Próximos passos para produção
- 📱 Lista completa de rotas

### [HIERARQUIA-VISUAL.md](./HIERARQUIA-VISUAL.md)
**Hierarquia visual de componentes**

Conteúdo:
- 🎮 Estrutura do componente principal (ExperimentFlowVertical)
- 📦 Hierarquia detalhada por seção (Header, Image, Actions)
- 🎨 Componentes reutilizáveis (FlatCoin, GameButton)
- 📊 State machine completo
- 🔄 Ciclo de vida de 1 tentativa
- 📁 Estrutura de importações

## 🎯 Para que serve cada documento?

| Documento | Quando usar |
|-----------|-------------|
| **TELAS-JOGO-VISUAL.txt** ⭐ | Ver mockups visuais de TODAS as telas, entender layout, mostrar para stakeholders |
| **ARQUITETURA-TELAS.md** | Entender fluxo completo de navegação, ver todas as rotas, conhecer estrutura de arquivos |
| **HIERARQUIA-VISUAL.md** | Entender como os componentes se conectam, ver estados e transições, debugar fluxo de dados |

## 🚀 Quick Start

1. **Ver mockups visuais de TODAS as telas:** ⭐ COMECE AQUI
   - Abra `TELAS-JOGO-VISUAL.txt`

2. **Ver todas as rotas disponíveis:**
   - Abra `ARQUITETURA-TELAS.md` → seção "Mapa de Navegação"

3. **Entender um componente específico:**
   - Abra `HIERARQUIA-VISUAL.md` → encontre a seção do componente

4. **Ver o fluxo completo de 1 tentativa:**
   - Abra `HIERARQUIA-VISUAL.md` → seção "Ciclo de Vida de 1 Tentativa"

5. **Ver lista completa de rotas:**
   - Abra `ARQUITETURA-TELAS.md` → seção "Rotas Completas"
